# C++ Course Code Examples

This repository contains C++ example code for a concept-focused tutoring course.

## Structure

```text
examples/
  01_hello/
  02_functions/
  03_multi_file/
  04_runtime_model/
scripts/
  run_normal.sh
Makefile
```

## Run

```sh
./scripts/run_normal.sh
```

Or build the main examples with:

```sh
make all
```

Generated files are written to `build/`.
